ダウンロード・インストール

アプリストアは使いません。ブラウザで開いて「ホーム画面に追加」するだけで、オフラインでも動くアプリとしてインストールされます。容量は数 MB です。

  1. Chrome でアプリを開くスマホの Chrome でこのページを開き、アプリを開くをタップします。パソコンで見ている場合は、QR コードをスマホのカメラで読み取ってください。
  2. 「ホーム画面に追加」をタップアプリの上部に出るホーム画面に追加ボタンを押します。表示されないときは、Chrome 右上の︙→ホーム画面に追加（またはアプリをインストール）を選びます。
  3. 「インストール」を確認確認画面でインストールを押すと、ホーム画面に赤いクルマのアイコンが追加されます。
  4. アイコンから起動以後はアイコンから開くだけ。電波がない場所でも記録できます。
  1. Safari でアプリを開くiPhone の Safari でこのページを開き、アプリを開くをタップします。パソコンで見ている場合は、QR コードを iPhone のカメラで読み取ってください。（Safari 以外のブラウザでは追加できない場合があります）
  2. 共有ボタンをタップ画面下（iPad は右上）の共有 □↑ボタンを押します。
  3. 「ホーム画面に追加」を選ぶメニューを下にスクロールしてホーム画面に追加→ 右上の追加。
  4. アイコンから起動ホーム画面のアイコンから開いてください。ブラウザから開いた場合とは記録の保存場所が分かれることがあるため、以後は必ずアイコンから使うのがおすすめです。
  1. Chrome または Edge でアプリを開くアプリを開くをクリックします。
  2. インストールボタンを押すアドレスバー右端のインストール ⊕アイコン、またはアプリ内のホーム画面に追加ボタンを押します。
  3. デスクトップやタスクバーから起動専用のウィンドウで開くアプリとして使えます。
  4. 自動バックアップを設定（おすすめ）「バックアップ・入出力」→「フォルダへの自動バックアップ」で保存先（Google Drive の同期フォルダなど）を選ぶと、開くたびに自動で保存されます。

インストールの前に

  1. 記録は端末ごと　記録はその端末のブラウザの中に保存されます。スマホとパソコンで自動的に同期はしません。別の端末へ移すときはバックアップを使います。
  2. バックアップを端末の外へ　ブラウザのデータ消去やアプリの削除で記録が消えることがあります。ときどきバックアップを作成し、Google Drive などに保存してください。
  3. このページは限定公開　URL を知っている人だけが開ける前提のページです。URL を不特定多数に共有しないでください。
